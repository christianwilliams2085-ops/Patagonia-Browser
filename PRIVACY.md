# Política de privacidad de Patagonia Browser

**Vigente desde el 3 de septiembre de 2026**

Patagonia Browser está diseñado para navegar con privacidad y sin una cuenta de usuario. Esta versión no incluye publicidad propia, analítica, telemetría ni servidores de Patagonia Browser que recopilen datos personales.

## Datos guardados en el dispositivo

Los favoritos, el historial y las preferencias se guardan localmente en el teléfono. Patagonia Browser no envía esos datos a sus desarrolladores. El historial se puede borrar desde la aplicación y todos los datos locales se eliminan al desinstalarla.

## Navegación y sitios externos

Cuando una persona visita un sitio o realiza una búsqueda, la dirección y la información necesaria para cargar la página se envían al sitio visitado o al proveedor de búsqueda elegido. Esos terceros pueden aplicar sus propias políticas de privacidad. Patagonia Browser bloquea dominios publicitarios y rastreadores conocidos, pero ningún bloqueador puede impedir todas las solicitudes de terceros.

## Cámara, micrófono y ubicación

Un sitio puede solicitar acceso a la cámara, al micrófono o a la ubicación. Patagonia Browser muestra una confirmación antes de responder a esa solicitud y iOS también controla el permiso del sistema. La aplicación no accede a estas funciones por iniciativa propia.

## Seguridad y conservación

Patagonia Browser usa el motor WebKit incluido en iOS. La aplicación no administra una base de datos externa ni conserva copias remotas del historial de navegación.

## Cambios y contacto

Las actualizaciones de esta política se publicarán en este mismo repositorio. Las consultas o reportes se pueden enviar mediante [GitHub Issues](https://github.com/christianwilliams2085-ops/Patagonia-Browser/issues).
