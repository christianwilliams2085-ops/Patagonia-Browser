# Descargas de Patagonia Browser para Windows

Patagonia es un navegador de escritorio en desarrollo con navegación por pestañas, favoritos, historial local y bloqueo de anuncios y rastreadores.

## Windows x64

- [Descargar el instalador de Patagonia Browser 1.0.4](https://github.com/christianwilliams2085-ops/Patagonia-Browser/releases/download/v1.0.4/Patagonia-Browser-Setup.exe).
- [Ver la publicación 1.0.4](https://github.com/christianwilliams2085-ops/Patagonia-Browser/releases/tag/v1.0.4).
- [Consultar todas las versiones publicadas](https://github.com/christianwilliams2085-ops/Patagonia-Browser/releases).

La versión 1.0.4 fue publicada el 7 de septiembre de 2026. El instalador actual está **sin firma de un proveedor reconocido** y Windows puede bloquear su ejecución.

## Code signing policy

Patagonia envió la solicitud al programa gratuito de SignPath Foundation el 8 de septiembre de 2026 y el formulario confirmó su recepción. La evaluación está pendiente. Todavía no hay aprobación ni un servicio de firma activo; las versiones disponibles no están firmadas por SignPath.

La [Code signing policy](CODE_SIGNING.md) identifica al mantenedor, las responsabilidades de firma, el origen verificable de las compilaciones y las condiciones pendientes. La atribución del proveedor se actualizará cuando el programa sea aprobado y las firmas estén en uso.

## Privacidad y desinstalación

Consultá la [política de privacidad de Windows](PRIVACY_WINDOWS.md) antes de instalar. Para desinstalar, abrí Configuración de Windows, buscá Patagonia Browser en las aplicaciones instaladas y seleccioná Desinstalar. El perfil local puede conservarse; la política explica cómo eliminar sus datos.
